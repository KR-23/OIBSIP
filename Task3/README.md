# OIBSIP Task 3 - Temperature Converter

## Overview

This project is a modern and responsive Temperature Converter web application. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin through a simple and interactive interface.

The application includes a clean dark-themed design with gradient colors, animated background elements, and easy-to-use conversion controls.

## Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Display temperature values with two decimal places
- Optional Kelvin conversion display
- Input validation for temperature values
- Interactive radio buttons for unit selection
- Modern dark-themed user interface
- Gradient color effects
- Responsive design for different screen sizes
- Animated decorative background elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox

- Media Queries
- DOM Manipulation

##How to Run
- Download or clone the repository.
- Open the Task3 project folder.
- Run index.html in any modern web browser.
- Enter a temperature value.
- Select Celsius or Fahrenheit as the input unit.
- Click the Convert Now button to view the converted temperature.

##Conversion Formula Used
###Celsius to Fahrenheit
°F = (°C × 9/5) + 32
###Fahrenheit to Celsius
°C = (°F - 32) × 5/9
###Celsius to Kelvin
K = °C + 273.15
